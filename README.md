# JavaFoundations01

Exercícios desenvolvidos durante o curso **Programação Oracle - Java Foundations**, certificado pelo SENAI-SP, com uma progressão que vai dos fundamentos da linguagem até conceitos avançados de orientação a objetos.

Este repositório é um fork de [JavaFoundations-I1-2026/JavaFoundations01](https://github.com/JavaFoundations-I1-2026/JavaFoundations01), com as soluções desenvolvidas ao longo das aulas — base para os projetos gráficos seguintes, [ProjetoFX01](https://github.com/LucasPereirax/ProjetoFX01) e [ProjetoFX2](https://github.com/LucasPereirax/ProjetoFX2).

## Progressão de conceitos

- **Fundamentos** (`aula1`–`aula4`): tipos de dados, operadores, strings, arrays, estruturas de decisão e repetição, listas
- **Classes e objetos** (`aula5`): encapsulamento (`ContaBancaria`), relacionamento entre classes (`Pessoa`)
- **Herança e polimorfismo** (`aula5`/`atividade05`, `aula6`, `aula7`): hierarquias como `Animal` → `Cachorro`/`Gato`/`Capivara`, `Funcionario` → `Gerente`, `Veiculo` → `Carro`/`Moto`
- **Agregação vs. composição** (`aula8`): comparando um relacionamento de agregação (`Selecao`/`Tecnico`) com um de composição (`Carro`/`Motor`)
- **Sistemas mais completos** (`aula8/atividade12`, `atividade13`): um mini sistema de biblioteca (`Biblioteca`, `Livro`, `Aluno`, `Funcionario`, `Pessoa`) e um sistema de **RPG** com personagens especializados (`Personagem` → `Arqueiro`, `Guerreiro`, `Mago`, cada um com sua `Arma`)

## Tecnologias

- Java
