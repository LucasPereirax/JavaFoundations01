# JavaFoundations01

Exercícios desenvolvidos durante o curso **Programação Oracle - Java Foundations**, certificado pelo SENAI-SP, cobrindo os fundamentos da linguagem Java com foco em boas práticas de codificação.

Este repositório é um fork de [JavaFoundations-I1-2026/JavaFoundations01](https://github.com/JavaFoundations-I1-2026/JavaFoundations01), com as soluções desenvolvidas ao longo das aulas — base para os projetos seguintes, como [ProjetoFX01](https://github.com/LucasPereirax/ProjetoFX01) e [ProjetoFX2](https://github.com/LucasPereirax/ProjetoFX2).

## Conceitos praticados

- Configuração de ambiente de desenvolvimento Java
- Sintaxe Java conforme boas práticas
- Estruturas de decisão e repetição
- Programação orientada a objetos (herança, polimorfismo)
- Matrizes e listas
- Tratamento de exceções
- Técnicas de depuração e identificação de erros

## Tecnologias

- Java

## Rodando o projeto localmente

```bash
git clone https://github.com/LucasPereirax/JavaFoundations01.git
```

Abra o projeto na sua IDE de preferência (IntelliJ, Eclipse, VS Code) e execute as classes dentro de `src/`.
